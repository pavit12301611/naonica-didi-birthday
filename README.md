# Happy Birthday Naonica Didi 🎂

A beautiful, mobile-first multipage birthday surprise website — made with love, just for **NAONICA DIDI**.

Live preview → run `python3 -m http.server 8000` and open `index.html` (mobile view recommended).

### Pages
- **Home** (`index.html`) — Hero, countdown, why we love you, quick navigation
- **Letter** (`letter.html`) — Heartfelt handwritten letter on premium paper
- **Memories** (`memories.html`) — Polaroid gallery (tap to lightbox, replace with your real photos)
- **Wishes** (`wishes.html`) — Wishes wall + form (saves to localStorage) + Dua
- **Surprise** (`surprise.html`) — Interactive 3-tier cake: tap flames to blow, mic blow, confetti, gift unwrap

### Features
- 📱 **Mobile-first** with bottom tab bar, sticky header, thumb-friendly buttons
- 🎶 Music toggle, 🎉 confetti cannon, 🕯️ interactive candles, 🎀 gift reveal
- ✨ Editorial design: Playfair + Great Vibes, plum/rose/gold palette, glassmorphism
- 🖼️ Lightbox gallery, local wish storage, share button (Web Share API + clipboard fallback)
- 🔒 Pure HTML/CSS/JS — no build step, works on any static host (Netlify, Vercel, GitHub Pages)

### Customize
- Replace gallery images in `memories.html` (search `images.unsplash.com`)
- Edit wishes in `wishes.html` or let family add via the form
- Change name/date in `index.html` + `letter.html`
- Swap audio src in `<audio id="bgAudio">` for your own song

### Deploy
```bash
# GitHub Pages: push to main and enable Pages (root)
# Netlify/Vercel: drag & drop the folder
```
